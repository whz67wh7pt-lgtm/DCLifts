## GitHub Pages

1. Upload the contents of this folder to the repository root.
2. In GitHub: Settings > Pages.
3. Deploy from branch: main / root.
4. The CNAME file is already set to datacentrelifts.co.uk.
5. Point the domain DNS to GitHub Pages only when ready to launch.

## Before launch

- Replace/confirm all images.
- Confirm the four Comms Online product URLs are live.
- Confirm the best Comms Online URL for hire enquiries.
- Add GA4 / Google Ads tracking when required.
- Submit sitemap.xml in Google Search Console.
